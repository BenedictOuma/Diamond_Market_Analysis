# Diamond Market Analysis

Welcome to the **Diamond Market Analysis** project by *GemValue Analytics*.  
This project aims to uncover the key factors that influence diamond prices using a dataset of over **50,000 diamonds**, applying data cleaning, exploratory analysis, and visual storytelling techniques.

---

## Learning Objectives

By the end of this project, you should be able to:

- Clean and preprocess a structured dataset using **Pandas**
- Use **group-based aggregation** to extract insights
- Visualize relationships using **Seaborn** and **Matplotlib**
- Detect **outliers**, **skewed distributions**, and **multicollinearity**
- Explore how diamond features impact price
- Identify the **top three features affecting price**
- Use visual tools to tell a **compelling, data-driven story**

---

## Tools & Technologies

- **Python** (Jupyter Notebook)
- **Pandas**
- **Seaborn**

---

## Key Analytical Steps

### 1. Data Cleaning & Preprocessing
- Handled missing values and duplicates
- Converted data types
- Removed extreme outliers based on price and dimensions

### 2. Exploratory Data Analysis (EDA)
- Analyzed distributions of carat, cut, clarity, depth, etc.
- Explored correlations between features
- Detected skewness and multicollinearity

### 3. Price Analysis
- Identified how price varies with **carat**, **cut**, **clarity**, and **color**
- Used **boxplots**, **scatterplots**, and **violin plots** to reveal patterns
- Ranked features based on their impact on price

### 4. Business Insights
- Highlighted the **top three features** influencing diamond prices
- Provided actionable takeaways for jewelry business stakeholders
